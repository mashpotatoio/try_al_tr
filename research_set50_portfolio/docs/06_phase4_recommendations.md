# Phase 4 decision gate

Do not train a machine-learning model from these results. The trend hypotheses have weak Phase 2 rank evidence, the one-day reversal effect is smaller than round-trip friction, and Phase 3 uses previously exposed dates. First reconcile adjusted daily opens with raw tick prices, inspect official practice fills and timestamps, and collect new untouched chronological windows. Only a surviving positive net-excess hypothesis with reliable labels and enough fresh windows would justify a regularized model comparison.
