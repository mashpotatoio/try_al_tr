# SET50 baseline research — Phase 1

This repository contains a transparent, reproducible TradeSim research package and an executed comparison notebook for five baseline strategies: buy-and-hold, cross-sectional momentum, relative strength with inverse-volatility sizing, an equal-weight sizing control, and RSI(14) oversold.

Start with [`research_set50_baseline/notebooks/01_set50_baseline_comparison.ipynb`](research_set50_baseline/notebooks/01_set50_baseline_comparison.ipynb), then read the [architecture](research_set50_baseline/docs/ARCHITECTURE.md), [five-phase roadmap](research_set50_baseline/docs/ROADMAP.md), and [findings](research_set50_baseline/RESEARCH_FINDINGS.md).

The native simulator run covers 16 available sessions, not the full competition period. The compact results and rendered notebook are included. Reproducing backtests requires the separate TradeSim project and market data; they are not included in this repository. Daily-open research fills do not establish official competition eligibility.
